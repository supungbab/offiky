# 낚시 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 조종 중 `F` 로 낚싯대를 펴 연못에서 기다리다 입질이 오면 `X` 로 챔질해 물고기를 들어 올린다. 동료 화면에도 같이 보인다.

**Architecture:** 춤(`isDancing`·`canDance`·`placeDiscos`·`crowds`)과 무기(`drawWeapon`·`weapon` 노드)의 구조를 그대로 따른다. 상태는 `CharacterNode` 에 두고 `PosMsg` 옵셔널 필드로 보내며, 연못은 `World` 가 무대 타일처럼 띠 좌표에 깐다. 입질·챔질 판정은 낚시하는 사람만 한다.

**Tech Stack:** Swift · SpriteKit · Swift Testing · Python(Pillow) 에셋 스크립트

**Spec:** `docs/superpowers/specs/2026-11-11-fishing-design.md`

## Global Constraints

- `protocolVersion` 은 바꾸지 않는다. 새 `PosMsg` 필드는 옵셔널이고 값이 있을 때만 적는다.
- 물고기 번호는 1부터, 뒤에 추가만 한다.
- 에셋은 Pillow 스크립트로 그리고 2배로 띄운다. 1px 선을 피한다. 움직이는 것은 프레임마다 통째로 그린 스트립이다.
- 펴기·접기 조건은 `canDance(now:)` 와 같다.
- 타이밍: 입질까지 5~20초, 입질 1.5초, 들어 올리기 2초.
- `World` 는 환경설정에 따라 달라지므로 `CharacterNode` 단위와 순수 함수로 검증한다.
- 주석은 없거나 한 줄. 커밋 메시지는 한국어 `feat:`/`fix:` 형식, 끝에 `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- 조작키를 추가하면 `HintView`·README 기능 표·DEBUG `Bot` 세 곳에 함께 반영한다.

## Review Focus

- 낚시 중 춤을 시작하면 낚시가 접히고, 춤 중 낚시를 펴면 춤이 멈춘다 → Task 2 테스트.
- 입질을 놓친 뒤 대기 시간이 처음부터 다시 잰다(바로 다음 입질이 오지 않는다) → Task 2 테스트.
- 물고기를 들어 보이는 2초 동안 챔질·입질이 없다 → Task 2 테스트.
- 옛 버전이 보낸 `PosMsg` 에 새 필드가 없어도 디코딩되고 서 있는 캐릭터로 본다 → Task 3 테스트.
