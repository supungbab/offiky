# offiky Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 같은 사내 네트워크의 맥 사용자들이 데스크톱 바닥 위 16×16 픽셀 캐릭터로 서로의 존재를 보고, 전역 단축키로 한 줄 메시지를 주고받는 메뉴바 상주 앱을 만든다.

**Architecture:** 디스플레이마다 전체 화면 투명 오버레이 윈도우 1개를 배치하고 그 안의 SpriteKit 씬이 그 화면에 속한 캐릭터를 렌더링한다. 서버 없이 Bonjour 로 서로를 발견하고 `id` 오름차순으로 자동 선출된 호스트가 위치·채팅·프로필을 중계한다. 좌표는 화면들의 폭을 이어 붙인 바닥 띠 위의 포인트 절대값이며, 각자의 데스크톱 폭이 자기 캐릭터의 벽이다.

**Tech Stack:** Swift 5, SwiftUI (`MenuBarExtra`), AppKit (`NSWindow`, `NSPanel`), SpriteKit, Network.framework (`NWListener`/`NWBrowser`/`NWConnection`), Swift Testing, `KeyboardShortcuts` (SPM)

**Spec:** `docs/superpowers/specs/2026-09-15-offiky-design.md`

## Global Constraints

- 대상 플랫폼: macOS 26.0 이상, App Sandbox 활성화
- 스프라이트: 16×16 픽셀을 16×16 포인트로 표시(1:1), `SKTexture.filteringMode = .nearest`
- 씬 렌더링: `preferredFramesPerSecond = 12`
- 스프라이트 인코딩: 16줄 × 16자, 문자는 `0`–`9`, `a`–`f`(팔레트 인덱스), `.`(투명)만 허용. 대문자 불가
- 팔레트: PICO-8 16색 고정
- 좌표: `x`·`y` 모두 포인트 절대값. `x` 는 스프라이트 **중심** 좌표, `y` 는 바닥으로부터의 높이
- 벽: 내 캐릭터는 `[8, 띠 길이 − 8]` 안에서만 이동한다 (스프라이트 폭 16의 절반)
- 중력: 2400 pt/s². 점프 정점 24pt
- 프로토콜: 줄바꿈으로 구분한 UTF-8 JSON. 버전 필드는 `pv`, 현재 값 `1`
- 입력 검증: 형식 위반(16KB 초과·JSON 파싱 실패·`pv` 불일치)만 연결 종료. 내용 위반은 대체·무시
- 한계값: 이름 1~20자, 채팅 1~200자, `x` 0~20000, `y` 0~4000
- `id` 는 앱 실행마다 새로 생성하는 UUID. 이름·스프라이트·거점은 `UserDefaults` 에 보관
- 해시는 반드시 **FNV-1a 같은 고정 해시**를 쓴다. Swift 의 `hashValue` 는 프로세스마다 시드가 달라 맥끼리 결과가 달라진다

`offiky.xcodeproj/project.pbxproj` 에서 **`offiky` 타깃의 Debug·Release 두 블록** 모두 수정한다. `offikyTests`·`offikyUITests` 블록은 건드리지 않는다.

`offiky` 타깃 블록은 `PRODUCT_BUNDLE_IDENTIFIER = com.offiky;` 가 있는 블록이다.

**`GENERATE_INFOPLIST_FILE` 은 반드시 `YES` 로 둔다.** `NO` 로 두면 Xcode 가
`CFBundleIdentifier`·`CFBundleExecutable` 같은 표준 키를 더 이상 주입하지 않고, 샌드박스가
컨테이너를 만들 때 번들 식별자를 찾지 못해 **앱이 실행 즉시 `_libsecinit_appsandbox` 에서
죽는다.** `YES` 와 `INFOPLIST_FILE` 을 함께 지정하면 Xcode 가 표준 키를 이 파일에 병합한다.

파일 시스템 동기화 그룹이 `offiky/Info.plist` 를 리소스로도 복사해 경고가 발생한다.
`PBXFileSystemSynchronizedBuildFileExceptionSet` 을 추가해 제외한다. `pbxproj` 의
`PBXFileSystemSynchronizedRootGroup` 섹션 앞에 다음을 넣고, `offiky` 그룹에
`exceptions = ( <새 id> );` 를 추가한다.

```
/* Begin PBXFileSystemSynchronizedBuildFileExceptionSet section */
		<새 id> /* Exceptions for "offiky" folder in "offiky" target */ = {
			isa = PBXFileSystemSynchronizedBuildFileExceptionSet;
			membershipExceptions = (
				Info.plist,
			);
			target = <offiky 네이티브 타깃 id>;
		};
/* End PBXFileSystemSynchronizedBuildFileExceptionSet section */
```

- [ ] **Step 5: 최소 오버레이 구현**

`offiky/OverlayController.swift`:

```swift
import AppKit
import SpriteKit

final class OverlayController {
    static let shared = OverlayController()

    private(set) var windows: [NSWindow] = []
    private(set) var scenes: [SKScene] = []

    private init() {}

    func start() {
        rebuild()
        NotificationCenter.default.addObserver(
            self, selector: #selector(screensChanged),
            name: NSApplication.didChangeScreenParametersNotification, object: nil)
    }

    @objc private func screensChanged() { rebuild() }

    func rebuild() {
        windows.forEach { $0.orderOut(nil) }
        windows.removeAll()
        scenes.removeAll()

        let frames = NSScreen.screens
            .map(\.visibleFrame)
            .sorted { ($0.minX, $0.minY) < ($1.minX, $1.minY) }

        for frame in frames {
            let window = NSWindow(contentRect: frame, styleMask: .borderless,
                                  backing: .buffered, defer: false)
            window.isOpaque = false
            window.backgroundColor = .clear
            window.hasShadow = false
            window.level = .floating
            window.collectionBehavior = [.canJoinAllSpaces, .stationary, .fullScreenAuxiliary]
            window.ignoresMouseEvents = false

            let view = SKView(frame: CGRect(origin: .zero, size: frame.size))
            view.allowsTransparency = true
            let scene = SKScene(size: frame.size)
            scene.backgroundColor = .clear
            scene.scaleMode = .resizeFill
            view.preferredFramesPerSecond = 12
            view.presentScene(scene)

            window.contentView = view
            window.setFrame(frame, display: true)
            window.orderFrontRegardless()

            windows.append(window)
            scenes.append(scene)
        }
    }

    /// 클릭 통과 검증용. Task 4 에서 제거한다.
    func addProbeSquare() {
        guard let scene = scenes.first else { return }
        let node = SKSpriteNode(color: .systemRed, size: CGSize(width: 120, height: 120))
        node.position = CGPoint(x: 200, y: 200)
        scene.addChild(node)
    }
}
```

```swift
struct SpriteTests {
```

```swift
import CoreGraphics
import Foundation

/// 프로세스마다 시드가 바뀌는 Swift 의 hashValue 와 달리 맥끼리 같은 값을 낸다.
/// 캐릭터 색과 초기 위치를 모든 피어가 동일하게 계산해야 하므로 필수다.
func stableHash(_ s: String) -> UInt64 {
    var h: UInt64 = 0xcbf29ce484222325
    for byte in s.utf8 {
        h ^= UInt64(byte)
        h = h &* 0x100000001b3
    }
    return h
}

enum Palette {
    /// PICO-8 16색
    static let rgb: [UInt32] = [
        0x000000, 0x1D2B53, 0x7E2553, 0x008751,
        0xAB5236, 0x5F574F, 0xC2C3C7, 0xFFF1E8,
        0xFF004D, 0xFFA300, 0xFFEC27, 0x00E436,
        0x29ADFF, 0x83769C, 0xFF77A8, 0xFFCCAA,
    ]
    /// 착지 먼지 색 (AB5236)
    static let dustIndex = 4
}

struct Sprite: Equatable {
    static let size = 16
    private static let allowed = Set("0123456789abcdef.")

    /// 16줄 × 16자. 각 문자는 팔레트 인덱스이거나 `.`(투명)
    let rows: [String]

    init?(encoded: String) {
        let lines = encoded.components(separatedBy: "\n")
        guard lines.count == Sprite.size else { return nil }
        for line in lines {
            guard line.count == Sprite.size,
                  line.allSatisfy({ Sprite.allowed.contains($0) })
            else { return nil }
        }
        self.rows = lines
    }

    private init(validatedRows: [String]) { self.rows = validatedRows }

    var encoded: String { rows.joined(separator: "\n") }

    // MARK: 기본 캐릭터

    /// 소스 내부 표현. 외부로 전송되지 않는다.
    private static let template = [
        "................",
        ".....######.....",
        "....#HHHHHH#....",
        "...#HHHHHHHH#...",
        "...#HHHHHHHH#...",
        "...#HSSSSSSH#...",
        "...#HSESSESH#...",
        "...#HSSSSSSH#...",
        "....#SSSSSS#....",
        ".....#SSSS#.....",
        "......#SS#......",
        "...#BBBBBBBB#...",
        "..#SBBBBBBBBS#..",
        "..#SBBBBBBBBS#..",
        "...#BBBBBBBB#...",
        "...#WW#..#WW#...",
    ]

    private static let hairColors: [Character] = ["0", "1", "2", "4", "5", "9", "d", "e"]
    private static let shirtColors: [Character] = ["2", "3", "8", "9", "b", "c", "d", "e"]

    /// 편집기를 사용하지 않은 사용자의 캐릭터. 색 조합은 64가지이며 고유하지 않다.
    static func standard(for id: String) -> Sprite {
        let h = stableHash(id)
        let hair = hairColors[Int(h % 8)]
        let shirt = shirtColors[Int((h / 8) % 8)]
        let map: [Character: Character] = [
            ".": ".", "#": "0", "S": "f", "E": "0", "W": "5",
            "H": hair, "B": shirt,
        ]
        let rows = template.map { String($0.map { map[$0] ?? "." }) }
        return Sprite(validatedRows: rows)
    }

    // MARK: 이미지

    func cgImage() -> CGImage? {
        let n = Sprite.size
        var pixels = [UInt8](repeating: 0, count: n * n * 4)
        for (y, row) in rows.enumerated() {
            for (x, ch) in row.enumerated() {
                guard let index = ch.hexDigitValue, index < Palette.rgb.count else { continue }
                let color = Palette.rgb[index]
                let offset = (y * n + x) * 4
                pixels[offset]     = UInt8((color >> 16) & 0xFF)
                pixels[offset + 1] = UInt8((color >> 8) & 0xFF)
                pixels[offset + 2] = UInt8(color & 0xFF)
                pixels[offset + 3] = 255
            }
        }
        guard let provider = CGDataProvider(data: Data(pixels) as CFData) else { return nil }
        return CGImage(
            width: n, height: n, bitsPerComponent: 8, bitsPerPixel: 32,
            bytesPerRow: n * 4, space: CGColorSpaceCreateDeviceRGB(),
            bitmapInfo: CGBitmapInfo(rawValue: CGImageAlphaInfo.premultipliedLast.rawValue),
            provider: provider, decode: nil, shouldInterpolate: false,
            intent: .defaultIntent)
    }
}
```

`hexDigitValue` 는 `.` 에 대해 `nil` 을 반환하므로 투명 픽셀은 자연히 건너뛴다. 대문자 `A` 는 `hexDigitValue` 가 `10` 이지만 `init?` 이 먼저 거부한다.

```swift
import CoreGraphics
import Foundation

let protocolVersion = 1
let spriteDisplaySize: CGFloat = 16

enum Limits {
    static let maxMessageBytes = 16 * 1024
    static let maxName = 20
    static let maxChat = 200
    static let maxX: Double = 20_000
    static let maxY: Double = 4_000
}

// MARK: - 바닥 띠

struct Placement: Equatable {
    let screenIndex: Int
    /// 해당 화면 오버레이 윈도우의 씬 로컬 좌표
    let point: CGPoint
}

struct FloorStrip {
    /// visibleFrame 을 (minX, minY) 오름차순으로 정렬한 것
    let frames: [CGRect]

    init(visibleFrames: [CGRect]) {
        self.frames = visibleFrames.sorted { ($0.minX, $0.minY) < ($1.minX, $1.minY) }
    }

    var length: CGFloat { frames.reduce(0) { $0 + $1.width } }

    /// `x` 는 스프라이트 중심, `y` 는 바닥으로부터의 높이. 둘 다 포인트.
    /// 띠에서 완전히 벗어나면 nil 을 반환한다.
    func place(x: CGFloat, y: CGFloat) -> Placement? {
        guard !frames.isEmpty else { return nil }
        let half = spriteDisplaySize / 2
        guard x + half >= 0, x - half <= length else { return nil }

        var accumulated: CGFloat = 0
        for (index, frame) in frames.enumerated() {
            let isLast = index == frames.count - 1
            if x < accumulated + frame.width || isLast {
                let maxY = max(0, frame.height - spriteDisplaySize)
                return Placement(
                    screenIndex: index,
                    point: CGPoint(x: x - accumulated, y: half + min(y, maxY)))
            }
            accumulated += frame.width
        }
        return nil
    }

    /// 내 캐릭터의 이동 범위. 양 끝이 벽이다.
    func clampToWall(_ x: CGFloat) -> CGFloat {
        let half = spriteDisplaySize / 2
        guard length > spriteDisplaySize else { return min(max(x, 0), length) }
        return min(max(x, half), length - half)
    }
}

// MARK: - 호스트 선출

/// 보이는 피어 중 id 가 가장 작은 쪽이 호스트다. 투표하지 않는다.
/// 나는 언제나 후보에 포함되므로 혼자여도 답이 나온다.
func electHost(candidates: Set<String>, excluded: Set<String>, me: String) -> String {
    var pool = candidates.subtracting(excluded)
    pool.insert(me)
    return pool.min()!
}

// MARK: - 중복 제거

/// 피어별 마지막 seq 정수 하나로 판정한다. 최근 기록으로 판정하면
/// 오래 지나 도착한 재전송을 검출하지 못한다.
struct SeqTracker {
    private var last: [String: Int] = [:]

    mutating func accept(id: String, seq: Int) -> Bool {
        if let previous = last[id], seq <= previous { return false }
        last[id] = seq
        return true
    }

    mutating func forget(id: String) { last[id] = nil }
}

// MARK: - 입력 정리

private func stripControls(_ s: String) -> String {
    s.filter { !$0.unicodeScalars.contains(where: { CharacterSet.controlCharacters.contains($0) }) }
}

/// 이름은 형식 위반이어도 연결을 끊지 않는다. 자르고 채운다.
func sanitizeName(_ raw: String) -> String {
    let cleaned = stripControls(raw).trimmingCharacters(in: .whitespaces)
    if cleaned.isEmpty { return "?" }
    return String(cleaned.prefix(Limits.maxName))
}

/// 채팅은 길이를 벗어나면 그 메시지만 무시한다.
func validChat(_ raw: String) -> String? {
    let cleaned = stripControls(raw)
    guard !cleaned.isEmpty, cleaned.count <= Limits.maxChat else { return nil }
    return cleaned
}

// MARK: - 메시지

struct Envelope: Decodable { let t: String }

struct PeerPos: Codable {
    let id: String
    let x: Double
    let y: Double?
}

struct HelloMsg: Codable {
    var t = "hello"
    var pv = protocolVersion
    let id: String
    let name: String
    let sprite: String
}

struct PosMsg: Codable {
    var t = "pos"
    let x: Double
    /// 바닥에 있으면 전송하지 않는다
    let y: Double?
}

struct SayMsg: Codable {
    var t = "say"
    /// 클라이언트가 보낼 때는 없고, 호스트가 중계할 때 채운다
    var id: String?
    let seq: Int
    let msg: String
}

struct ProfileMsg: Codable {
    var t = "profile"
    var id: String?
    let name: String
    let sprite: String
}

struct JoinMsg: Codable {
    var t = "join"
    let id: String
    let name: String
    let sprite: String
}

struct LeaveMsg: Codable {
    var t = "leave"
    let id: String
}

struct SnapMsg: Codable {
    var t = "snap"
    let p: [PeerPos]
}

struct AckMsg: Codable {
    var t = "ack"
    let seq: Int
}
```

```swift
    private let image = SKSpriteNode()
    private let label = SKLabelNode(fontNamed: "Helvetica")

    // 로컬 시뮬레이션 상태
    private var verticalSpeed: CGFloat = 0
    private var walkTarget: CGFloat = 0
    private var nextWalkAt: TimeInterval = 0
    private var nextJumpAt: TimeInterval = 0
    var isDragging = false

    // 렌더링 전용
    private var bobPhase: CGFloat = 0
    private var wasAirborne = false

    // 원격 보간
    private var fromX: CGFloat = 0, fromY: CGFloat = 0
    private var toX: CGFloat = 0, toY: CGFloat = 0
    private var interpolatedFor: TimeInterval = 0
    private static let interpolationDuration: TimeInterval = 0.5

    init(id: String, name: String, isLocal: Bool) {
        self.id = id
        self.name = name
        self.isLocal = isLocal
        super.init()

        image.size = CGSize(width: spriteDisplaySize, height: spriteDisplaySize)
        addChild(image)

        label.fontSize = 10
        label.fontColor = .white
        label.verticalAlignmentMode = .bottom
        label.position = CGPoint(x: 0, y: spriteDisplaySize / 2 + 2)
        label.isHidden = true
        addChild(label)

        isUserInteractionEnabled = false
    }

    required init?(coder: NSCoder) { fatalError() }

    func apply(sprite: Sprite) {
        guard let cg = sprite.cgImage() else { return }
        let texture = SKTexture(cgImage: cg)
        texture.filteringMode = .nearest
        image.texture = texture
    }

    /// 호스트 스냅샷을 받았을 때 호출한다. 0.5초에 걸쳐 보간한다.
    func setRemoteTarget(x newX: CGFloat, y newY: CGFloat) {
        fromX = x; fromY = y
        toX = newX; toY = newY
        interpolatedFor = 0
    }

    func update(dt: TimeInterval, now: TimeInterval, strip: FloorStrip) {
        if isLocal {
            simulate(dt: dt, now: now, strip: strip)
        } else {
            interpolate(dt: dt)
        }
        detectLanding()
        bobPhase += CGFloat(dt) * (isWalking ? 9 : 2)
    }

    // MARK: 로컬 시뮬레이션

    private var isWalking = false

    private func simulate(dt: TimeInterval, now: TimeInterval, strip: FloorStrip) {
        if isDragging { isWalking = false; return }

        // 세로 운동
        if y > 0 || verticalSpeed != 0 {
            verticalSpeed += -2400 * CGFloat(dt)
            y += verticalSpeed * CGFloat(dt)
            if y <= 0 { y = 0; verticalSpeed = 0 }
            isWalking = false
            return
        }

        // 점프
        if now >= nextJumpAt {
            nextJumpAt = now + Double.random(in: 30...90)
            verticalSpeed = (2 * 2400 * 24).squareRoot()   // 정점 24pt
            return
        }

        // 산책
        if now >= nextWalkAt {
            nextWalkAt = now + Double.random(in: 3...9)
            walkTarget = strip.clampToWall(anchorX + CGFloat.random(in: -150...150))
        }
        let delta = walkTarget - x
        if abs(delta) < 1 {
            isWalking = false
        } else {
            isWalking = true
            x = strip.clampToWall(x + (delta > 0 ? 1 : -1) * 20 * CGFloat(dt))
        }
    }

    private func interpolate(dt: TimeInterval) {
        interpolatedFor = min(CharacterNode.interpolationDuration, interpolatedFor + dt)
        let t = CGFloat(interpolatedFor / CharacterNode.interpolationDuration)
        x = fromX + (toX - fromX) * t
        y = fromY + (toY - fromY) * t
        isWalking = abs(toX - fromX) > 1
    }

    // MARK: 착지

    /// 걷기 진동은 시각 오프셋이라 여기에 포함하지 않는다.
    /// 포함하면 걸음마다 y 가 0 을 오르내려 걸을 때마다 먼지가 인다.
    private func detectLanding() {
        let airborne = y > 0
        if wasAirborne && !airborne {
            (scene as? CharacterScene)?.spawnDust(at: position, speed: abs(verticalSpeed))
            image.run(.sequence([
                .scaleY(to: 0.85, duration: 0.05),
                .scaleY(to: 1.0, duration: 0.08),
            ]))
        }
        wasAirborne = airborne
    }

    // MARK: 렌더링

    /// 씬 로컬 좌표와 이름 표시 여부를 반영한다.
    /// bob 은 position 에만 더하고 y 를 건드리지 않는다. y 에 섞으면
    /// 걸음마다 y 가 0 을 오르내려 걸을 때마다 착지 먼지가 인다.
    func render(placement: Placement, showName: Bool) {
        let bob: CGFloat = sin(bobPhase) > 0 ? 1 : 0
        position = CGPoint(x: placement.point.x, y: placement.point.y + bob)
        // 같은 x 에 선 두 캐릭터의 앞뒤가 프레임마다 바뀌지 않도록
        // id 고정 해시로 동률을 해소한다. 1pt 미만의 차이는 눈에 보이지 않는다.
        zPosition = x + CGFloat(stableHash(id) % 997) / 1000
        label.text = name
        label.isHidden = !showName
    }

    /// 말풍선을 표시 중인 캐릭터는 이름도 함께 표시한다 (Task 8 에서 사용)
    var forceName = false
}
```

```swift
final class World {
    static let shared = World()

    private(set) var me: CharacterNode
    private(set) var peers: [String: CharacterNode] = [:]

    private var scenes: [CharacterScene] = []
    private var strip = FloorStrip(visibleFrames: [])
    private var lastTick: TimeInterval = 0

    /// 이 실행에서만 유효한 id. 선출 기준이자 seq 의 짝이다.
    let myID = UUID().uuidString

    private init() {
        let name = sanitizeName(UserDefaults.standard.string(forKey: "name") ?? NSFullUserName())
        me = CharacterNode(id: myID, name: name, isLocal: true)
        me.apply(sprite: Self.storedSprite(for: myID))
    }

    static func storedSprite(for id: String) -> Sprite {
        if let encoded = UserDefaults.standard.string(forKey: "sprite"),
           let sprite = Sprite(encoded: encoded) {
            return sprite
        }
        return Sprite.standard(for: id)
    }

    func attach(scenes: [CharacterScene], strip: FloorStrip) {
        self.scenes = scenes
        self.strip = strip

        if UserDefaults.standard.object(forKey: "anchorX") == nil {
            // 첫 실행. 좁은 화면 동료에게도 보이도록 0~1200pt 안에 배치한다.
            let initial = CGFloat(stableHash(myID) % 1200)
            UserDefaults.standard.set(Double(initial), forKey: "anchorX")
        }
        let stored = CGFloat(UserDefaults.standard.double(forKey: "anchorX"))
        me.anchorX = strip.clampToWall(stored)
        me.x = me.anchorX
    }

    func tick(now: TimeInterval) {
        let dt = lastTick == 0 ? 1.0 / 12 : min(0.25, now - lastTick)
        lastTick = now

        // 1) 갱신하고, 속할 화면을 정하고, 보이지 않는 캐릭터를 걸러낸다
        var visible: [(node: CharacterNode, placement: Placement)] = []
        for node in [me] + Array(peers.values) {
            node.update(dt: dt, now: now, strip: strip)

            guard let placement = strip.place(x: node.x, y: node.y) else {
                node.removeFromParent()   // 내 띠에서 완전히 벗어났다
                continue
            }
            let scene = scenes[placement.screenIndex]
            // 경계를 넘을 때 노드를 씬 사이에서 옮긴다. 없으면 경계에서 사라진다.
            if node.parent !== scene {
                node.removeFromParent()
                scene.addChild(node)
            }
            visible.append((node, placement))
        }

        // 2) 커서에 가장 가까운 하나만 고른다.
        //    반경 안 전부를 표시하면 밀집 구간에서 이름표가 포개진다.
        let cursor = NSEvent.mouseLocation
        var nearestID: String?
        var nearestDistance = CGFloat.greatestFiniteMagnitude
        for (node, placement) in visible {
            let frame = strip.frames[placement.screenIndex]
            let global = CGPoint(x: frame.minX + placement.point.x,
                                 y: frame.minY + placement.point.y)
            let distance = hypot(global.x - cursor.x, global.y - cursor.y)
            if distance <= 60, distance < nearestDistance {
                nearestDistance = distance
                nearestID = node.id
            }
        }

        // 3) 그린다
        for (node, placement) in visible {
            node.render(placement: placement, showName: node.id == nearestID)
        }
    }
}
```

```swift
    func beginDrag() {
        me.isDragging = true
    }

    /// 전역 커서 좌표를 띠 좌표로 바꾼다. 가로는 벽으로 제한하고,
    /// 세로는 커서가 있는 화면의 바닥을 기준으로 잡는다.
    func updateDrag(toGlobal point: CGPoint) {

    }

    func commitAnchor() {
```

2. 놓으면 바닥까지 떨어진다

8. 앱을 종료하고 다시 실행하면 놓았던 자리 근처에 나타난다

`offiky/Mesh.swift`:

```swift
import Foundation
import Network

private let serviceType = "_offiky._tcp"

final class Mesh {
    static let shared = Mesh()

    private let queue = DispatchQueue(label: "offiky.mesh")
    private var listener: NWListener?
    private var browser: NWBrowser?

    /// 호스트일 때 수락한 클라이언트들
    private var clients: [String: NWConnection] = [:]
    /// 클라이언트일 때 호스트와의 연결
    private var upstream: NWConnection?

    private var visible: Set<String> = []
    private var excluded: [String: Date] = [:]
    private var currentHost: String?
    private var debounce: DispatchWorkItem?

    var isHost: Bool { currentHost == World.shared.myID }

    // 상위 계층이 채운다
    var onLine: ((Data, String?) -> Void)?

    private init() {}

    func start() {
        startListener()
        startBrowser()
    }

    func stop() {
        listener?.cancel(); listener = nil
        browser?.cancel(); browser = nil
        upstream?.cancel(); upstream = nil
        clients.values.forEach { $0.cancel() }
        clients.removeAll()
        visible.removeAll()
        currentHost = nil
    }

    // MARK: 광고

    private func startListener() {
        let params = NWParameters.tcp
        guard let listener = try? NWListener(using: params) else { return }
        // Bonjour 광고는 리스너가 담당한다. 열지 않으면 발견되지 않아
        // 선출 대상 집합에 포함되지 않는다.
        listener.service = NWListener.Service(
            name: World.shared.myID, type: serviceType,
            txtRecord: NWTXTRecord([
                "id": World.shared.myID,
                "pv": String(protocolVersion),
            ]).data)
        listener.newConnectionHandler = { [weak self] connection in
            self?.accept(connection)
        }
        listener.start(queue: queue)
        self.listener = listener
    }

    private func accept(_ connection: NWConnection) {
        // 분열 구간에 호스트가 아닌 피어에게도 연결이 들어온다.
        // 종료하면 상대가 재계산해 올바른 호스트로 이동한다.
        guard isHost else { connection.cancel(); return }
        let key = UUID().uuidString
        clients[key] = connection
        connection.stateUpdateHandler = { [weak self] state in
            if case .failed = state { self?.clients[key]?.cancel(); self?.clients[key] = nil }
            if case .cancelled = state { self?.clients[key] = nil }
        }
        connection.start(queue: queue)
        receiveLines(on: connection, from: key)
    }

    // MARK: 탐색

    private func startBrowser() {
        let descriptor = NWBrowser.Descriptor.bonjourWithTXTRecord(
            type: serviceType, domain: nil)
        let browser = NWBrowser(for: descriptor, using: .tcp)
        browser.browseResultsChangedHandler = { [weak self] results, _ in
            guard let self else { return }
            var ids: Set<String> = []
            for result in results {
                if case let .bonjour(txt) = result.metadata, let id = txt["id"] {
                    ids.insert(id)
                }
            }
            self.visible = ids
            self.scheduleElection()
        }
        browser.start(queue: queue)
        self.browser = browser
    }

    // MARK: 선출

    /// 여러 명이 동시에 합류·종료할 때 연쇄 재연결을 방지한다.
    private func scheduleElection() {
        debounce?.cancel()
        let work = DispatchWorkItem { [weak self] in self?.elect() }
        debounce = work
        queue.asyncAfter(deadline: .now() + 0.3, execute: work)
    }

    private func elect() {
        excluded = excluded.filter { Date().timeIntervalSince($0.value) < 10 }
        let host = electHost(
            candidates: visible,
            excluded: Set(excluded.keys),
            me: World.shared.myID)
        guard host != currentHost else { return }
        currentHost = host

        upstream?.cancel(); upstream = nil
        if !isHost { connectToHost(host) }
    }

    /// 연결이 끊어진 피어는 Bonjour 목록에서 사라지기를 기다리지 않고 즉시 제외한다.
    /// 비정상 종료 시 mDNS TTL 만료까지 수십 초가 걸린다.
    private func exclude(_ id: String) {
        excluded[id] = Date()
        scheduleElection()
    }

    private func connectToHost(_ id: String) {
        let endpoint = NWEndpoint.service(
            name: id, type: serviceType, domain: "local.", interface: nil)
        let connection = NWConnection(to: endpoint, using: .tcp)
        connection.stateUpdateHandler = { [weak self] state in
            switch state {
            case .ready: self?.onUpstreamReady?()
            case .failed, .cancelled: self?.exclude(id)
            default: break
            }
        }
        connection.start(queue: queue)
        upstream = connection
        receiveLines(on: connection, from: nil)
    }

    var onUpstreamReady: (() -> Void)?

    // MARK: 송수신

    private var buffers: [String: Data] = [:]

    private func receiveLines(on connection: NWConnection, from key: String?) {
        connection.receive(minimumIncompleteLength: 1, maximumLength: 64 * 1024) {
            [weak self] data, _, isComplete, error in
            guard let self else { return }
            if let data, !data.isEmpty {
                let bufferKey = key ?? "upstream"
                var buffer = self.buffers[bufferKey, default: Data()]
                buffer.append(data)
                while let newline = buffer.firstIndex(of: 0x0A) {
                    let line = buffer[buffer.startIndex..<newline]
                    buffer.removeSubrange(buffer.startIndex...newline)
                    // 형식 위반은 연결 종료. 내용 위반은 상위 계층이 대체·무시한다.
                    if line.count > Limits.maxMessageBytes {
                        connection.cancel(); return
                    }
                    if !line.isEmpty { self.onLine?(Data(line), key) }
                }
                self.buffers[bufferKey] = buffer
            }
            if isComplete || error != nil {
                connection.cancel()
                if key == nil, let host = self.currentHost { self.exclude(host) }
                return
            }
            self.receiveLines(on: connection, from: key)
        }
    }

    func sendToHost(_ data: Data) {
        var line = data; line.append(0x0A)
        upstream?.send(content: line, completion: .idempotent)
    }

    func broadcast(_ data: Data) {
        var line = data; line.append(0x0A)
        for connection in clients.values {
            connection.send(content: line, completion: .idempotent)
        }
    }

    func send(_ data: Data, toClient key: String) {
        var line = data; line.append(0x0A)
        clients[key]?.send(content: line, completion: .idempotent)
    }
}
```

`offiky/Session.swift`:

```swift
import Foundation
import CoreGraphics

final class Session {
    static let shared = Session()

    private var seq = 0
    private var pending: [SayMsg] = []
    private var tracker = SeqTracker()
    private var profiles: [String: (name: String, sprite: String)] = [:]
    private var positions: [String: PeerPos] = [:]
    private var clientIDs: [String: String] = [:]   // 연결 key -> peer id

    private var posTimer: Timer?
    private var snapTimer: Timer?
    private var lastPosSentAt: TimeInterval = 0

    var onChat: ((String, String) -> Void)?   // (보낸 사람 이름, 본문)

    var roster: [(id: String, name: String)] {
        ([(World.shared.myID, World.shared.me.name)]
         + profiles.map { ($0.key, $0.value.name) })
            .sorted { $0.1 < $1.1 }
    }

    private init() {}

    func start() {
        Mesh.shared.onLine = { [weak self] data, key in
            DispatchQueue.main.async { self?.handle(data, from: key) }
        }
        Mesh.shared.onUpstreamReady = { [weak self] in
            DispatchQueue.main.async { self?.sendHello() }
        }

        posTimer = Timer.scheduledTimer(withTimeInterval: 0.1, repeats: true) { [weak self] _ in
            self?.sendPositionIfDue()
        }
        snapTimer = Timer.scheduledTimer(withTimeInterval: 0.5, repeats: true) { [weak self] _ in
            self?.sendSnapshotIfHost()
        }
    }

    // MARK: 송신

    private func encode<T: Encodable>(_ value: T) -> Data {
        (try? JSONEncoder().encode(value)) ?? Data()
    }

    private func sendHello() {
        let me = World.shared.me
        Mesh.shared.sendToHost(encode(HelloMsg(
            id: World.shared.myID, name: me.name,
            sprite: World.storedSprite(for: World.shared.myID).encoded)))
        pending.forEach { Mesh.shared.sendToHost(encode($0)) }
    }

    /// 바닥에 있으면 0.5초마다, y > 0 인 동안에는 100ms 마다 전송한다.
    /// 점프·낙하·드래그가 모두 이 조건에 해당한다.
    private func sendPositionIfDue() {
        let now = ProcessInfo.processInfo.systemUptime
        let me = World.shared.me
        let interval: TimeInterval = me.y > 0 ? 0.1 : 0.5
        guard now - lastPosSentAt >= interval else { return }
        lastPosSentAt = now

        let msg = PosMsg(x: Double(me.x), y: me.y > 0 ? Double(me.y) : nil)
        if Mesh.shared.isHost {
            positions[World.shared.myID] = PeerPos(id: World.shared.myID, x: msg.x, y: msg.y)
        } else {
            Mesh.shared.sendToHost(encode(msg))
        }
    }

    /// 호스트 자신의 좌표도 스냅샷에 포함된다.
    private func sendSnapshotIfHost() {
        guard Mesh.shared.isHost else { return }
        let me = World.shared.me
        positions[World.shared.myID] = PeerPos(
            id: World.shared.myID, x: Double(me.x), y: me.y > 0 ? Double(me.y) : nil)
        Mesh.shared.broadcast(encode(SnapMsg(p: Array(positions.values))))
    }

    func sendSay(_ text: String) {
        guard let body = validChat(text) else { return }
        seq += 1
        let msg = SayMsg(id: World.shared.myID, seq: seq, msg: body)
        if Mesh.shared.isHost {
            // 즉시 전파되므로 대기열과 ack 를 사용하지 않는다
            Mesh.shared.broadcast(encode(msg))
        } else {
            pending.append(msg)
            Mesh.shared.sendToHost(encode(SayMsg(seq: seq, msg: body)))
        }
        onChat?(World.shared.me.name, body)
        World.shared.showBubble(id: World.shared.myID, text: body)
    }

    func sendProfile() {
        let me = World.shared.me
        let msg = ProfileMsg(
            id: World.shared.myID, name: me.name,
            sprite: World.storedSprite(for: World.shared.myID).encoded)
        if Mesh.shared.isHost {
            Mesh.shared.broadcast(encode(msg))
        } else {
            Mesh.shared.sendToHost(encode(ProfileMsg(name: me.name, sprite: msg.sprite)))
        }
    }

    // MARK: 수신

    private func handle(_ data: Data, from key: String?) {
        guard let envelope = try? JSONDecoder().decode(Envelope.self, from: data) else {
            return   // JSON 파싱 실패는 형식 위반. 연결은 Mesh 가 정리한다
        }
        switch envelope.t {
        case "hello":   handleHello(data, key: key)
        case "pos":     handlePos(data, key: key)
        case "say":     handleSay(data, key: key)
        case "profile": handleProfile(data, key: key)
        case "join":    handleJoin(data)
        case "leave":   handleLeave(data)
        case "snap":    handleSnap(data)
        case "ack":     handleAck(data)
        default: break
        }
    }

    private func handleHello(_ data: Data, key: String?) {
        guard Mesh.shared.isHost, let key,
              let msg = try? JSONDecoder().decode(HelloMsg.self, from: data),
              msg.pv == protocolVersion
        else { return }

        clientIDs[key] = msg.id
        let name = sanitizeName(msg.name)
        let sprite = Sprite(encoded: msg.sprite)?.encoded
            ?? Sprite.standard(for: msg.id).encoded
        profiles[msg.id] = (name, sprite)

        // 새로 접속한 클라이언트에게 알고 있는 피어 수만큼 join 을 연속 전송한다
        let me = World.shared.me
        Mesh.shared.send(encode(JoinMsg(
            id: World.shared.myID, name: me.name,
            sprite: World.storedSprite(for: World.shared.myID).encoded)), toClient: key)
        for (id, profile) in profiles where id != msg.id {
            Mesh.shared.send(encode(JoinMsg(
                id: id, name: profile.name, sprite: profile.sprite)), toClient: key)
        }
        Mesh.shared.broadcast(encode(JoinMsg(id: msg.id, name: name, sprite: sprite)))
        World.shared.addPeer(id: msg.id, name: name, sprite: sprite)
    }

    private func handlePos(_ data: Data, key: String?) {
        guard Mesh.shared.isHost, let key, let id = clientIDs[key],
              let msg = try? JSONDecoder().decode(PosMsg.self, from: data),
              msg.x >= 0, msg.x <= Limits.maxX,
              msg.y == nil || (msg.y! >= 0 && msg.y! <= Limits.maxY)
        else { return }
        positions[id] = PeerPos(id: id, x: msg.x, y: msg.y)
    }

    private func handleSnap(_ data: Data) {
        guard let msg = try? JSONDecoder().decode(SnapMsg.self, from: data) else { return }
        for p in msg.p {
            guard p.id != World.shared.myID,
                  p.x >= 0, p.x <= Limits.maxX,
                  p.y == nil || (p.y! >= 0 && p.y! <= Limits.maxY)
            else { continue }
            World.shared.setPeerTarget(id: p.id, x: CGFloat(p.x), y: CGFloat(p.y ?? 0))
        }
    }

    private func handleSay(_ data: Data, key: String?) {
        guard var msg = try? JSONDecoder().decode(SayMsg.self, from: data),
              let body = validChat(msg.msg) else { return }

        if Mesh.shared.isHost, let key, let id = clientIDs[key] {
            msg.id = id
            Mesh.shared.send(encode(AckMsg(seq: msg.seq)), toClient: key)
            Mesh.shared.broadcast(encode(SayMsg(id: id, seq: msg.seq, msg: body)))
        }
        guard let id = msg.id, id != World.shared.myID,
              tracker.accept(id: id, seq: msg.seq) else { return }
        onChat?(profiles[id]?.name ?? "?", body)
        World.shared.showBubble(id: id, text: body)
    }

    private func handleAck(_ data: Data) {
        guard let msg = try? JSONDecoder().decode(AckMsg.self, from: data) else { return }
        pending.removeAll { $0.seq <= msg.seq }
    }

    private func handleProfile(_ data: Data, key: String?) {
        guard var msg = try? JSONDecoder().decode(ProfileMsg.self, from: data) else { return }
        if Mesh.shared.isHost, let key, let id = clientIDs[key] {
            msg.id = id
            Mesh.shared.broadcast(encode(
                ProfileMsg(id: id, name: msg.name, sprite: msg.sprite)))
        }
        guard let id = msg.id, id != World.shared.myID else { return }
        let name = sanitizeName(msg.name)
        let sprite = Sprite(encoded: msg.sprite)?.encoded
            ?? Sprite.standard(for: id).encoded
        profiles[id] = (name, sprite)
        World.shared.addPeer(id: id, name: name, sprite: sprite)
    }

    private func handleJoin(_ data: Data) {
        guard let msg = try? JSONDecoder().decode(JoinMsg.self, from: data),
              msg.id != World.shared.myID else { return }
        let name = sanitizeName(msg.name)
        let sprite = Sprite(encoded: msg.sprite)?.encoded
            ?? Sprite.standard(for: msg.id).encoded
        profiles[msg.id] = (name, sprite)
        World.shared.addPeer(id: msg.id, name: name, sprite: sprite)
    }

    private func handleLeave(_ data: Data) {
        guard let msg = try? JSONDecoder().decode(LeaveMsg.self, from: data) else { return }
        profiles[msg.id] = nil
        positions[msg.id] = nil
        tracker.forget(id: msg.id)
        World.shared.removePeer(id: msg.id)
    }

    /// 대기열을 가진 클라이언트가 스스로 호스트가 되면 재전송할 상대가 없다.
    /// 직접 전원에게 전달하고 대기열을 비운다.
    func hostChanged() {
        if Mesh.shared.isHost {
            pending.forEach { Mesh.shared.broadcast(encode($0)) }
            pending.removeAll()
        }
    }
}
```

```swift
    /// 말풍선이 씬 경계를 벗어나지 않도록 가로 위치를 보정한다.
    func clampBubble(sceneWidth: CGFloat) {
        guard let bubble = childNode(withName: "bubble") as? SKShapeNode else { return }
        let half = bubble.frame.width / 2
        let left = position.x - half
        let right = position.x + half
        if left < 0 { bubble.position.x = half - position.x }
        else if right > sceneWidth { bubble.position.x = sceneWidth - half - position.x }
        else { bubble.position.x = 0 }
    }
}
```

```swift
import SwiftUI

struct SpriteEditorView: View {
    @State private var rows: [[Character]]
    @State private var selected: Character = "0"
    @State private var undoStack: [[[Character]]] = []

    private let cell: CGFloat = 22

    init() {
        let sprite = World.storedSprite(for: World.shared.myID)
        _rows = State(initialValue: sprite.rows.map(Array.init))
    }

    var body: some View {
        VStack(spacing: 12) {
            grid
            palette
            HStack {
                Button("기본 캐릭터로 초기화") {
                    push()
                    rows = Sprite.standard(for: World.shared.myID).rows.map(Array.init)
                }
                Spacer()
                Button("저장") { save() }.keyboardShortcut(.defaultAction)
            }
        }
        .padding(16)
        .background(
            Button("") { undo() }.keyboardShortcut("z", modifiers: .command).opacity(0))
    }

    private var grid: some View {
        VStack(spacing: 0) {
            ForEach(0..<16, id: \.self) { y in
                HStack(spacing: 0) {
                    ForEach(0..<16, id: \.self) { x in
                        Rectangle()
                            .fill(color(rows[y][x]))
                            .frame(width: cell, height: cell)
                            .border(Color.gray.opacity(0.3), width: 0.5)
                    }
                }
            }
        }
        .contentShape(Rectangle())
        .gesture(
            DragGesture(minimumDistance: 0)
                .onChanged { value in paint(at: value.location) }
                .onEnded { _ in strokeOpen = false })
    }

    @State private var strokeOpen = false

    private func paint(at point: CGPoint) {
        let x = Int(point.x / cell), y = Int(point.y / cell)
        guard (0..<16).contains(x), (0..<16).contains(y) else { return }
        if !strokeOpen { push(); strokeOpen = true }
        rows[y][x] = selected
    }

    private var palette: some View {
        HStack(spacing: 4) {
            ForEach(0..<16, id: \.self) { index in
                let ch = Character(String(index, radix: 16))
                swatch(ch, fill: color(ch))
            }
            swatch(".", fill: .clear)
        }
    }

    private func swatch(_ ch: Character, fill: Color) -> some View {
        Rectangle()
            .fill(fill)
            .frame(width: 22, height: 22)
            .overlay(Rectangle().stroke(
                selected == ch ? Color.accentColor : .gray.opacity(0.4),
                lineWidth: selected == ch ? 3 : 1))
            .onTapGesture { selected = ch }
    }

    private func color(_ ch: Character) -> Color {
        guard let index = ch.hexDigitValue, index < Palette.rgb.count else { return .clear }
        let rgb = Palette.rgb[index]
        return Color(red: Double((rgb >> 16) & 0xFF) / 255,
                     green: Double((rgb >> 8) & 0xFF) / 255,
                     blue: Double(rgb & 0xFF) / 255)
    }

    private func push() { undoStack.append(rows); if undoStack.count > 50 { undoStack.removeFirst() } }
    private func undo() { if let last = undoStack.popLast() { rows = last } }

    private func save() {
        let encoded = rows.map(String.init).joined(separator: "\n")
        guard let sprite = Sprite(encoded: encoded) else { return }
        UserDefaults.standard.set(sprite.encoded, forKey: "sprite")
        World.shared.me.apply(sprite: sprite)
        Session.shared.sendProfile()
    }
}

private var editorWindow: NSWindow?

func openSpriteEditor() {
    if let window = editorWindow { window.makeKeyAndOrderFront(nil); return }
    let window = NSWindow(
        contentRect: CGRect(x: 0, y: 0, width: 400, height: 500),
        styleMask: [.titled, .closable], backing: .buffered, defer: false)
    window.title = "내 캐릭터"
    window.contentView = NSHostingView(rootView: SpriteEditorView())
    window.center()
    window.isReleasedWhenClosed = false
    window.makeKeyAndOrderFront(nil)
    NSApp.activate(ignoringOtherApps: true)
    editorWindow = window
}
```
