# 낚시

조종 중에 낚싯대를 펴고 연못에서 물고기를 낚는다. 춤처럼 멈춰 서서 하는 놀이이고, 낚시하는 사람끼리 가까우면 연못이 이어진다.

## 조작

| 키 | 동작 |
|---|---|
| `F` | 바닥에서 낚싯대를 편다. 다시 누르면 접는다 |
| `X` | 낚싯대를 든 동안 챔질. 입질 중이면 잡고, 아니면 찌만 튀고 벌칙은 없다 |

- 펴는 조건은 춤과 같다(`canDance`): 바닥에 멈춰 있고, 숙이지·맞지·죽지·일하지·타지·끌리지 않는다.
- 접히는 조건도 춤과 같다. 움직이거나(←→), 점프, 숙이기, 오토바이, W, 맞으면 접힌다. 춤처럼 esc 로 조종을 끝내도 그대로 두고, 화면이 꺼지거나 잠기면(자리 비움) 접힌다. 춤을 시작해도 접히고, 낚싯대를 펴면 춤이 멈춘다.
- 낚싯대를 든 동안 `X` 는 무기를 쓰지 않는다. 들고 있던 무기는 그대로 둔 채 낚싯대만 표시한다(무기 번호는 유지, 그리기만 낚싯대로).

## 보이는 것

- 캐릭터가 바라보는 쪽 앞으로 낚싯대를 뻗고, 낚싯줄 끝에 찌가 연못 위에 떠 있다.
- 연못은 바닥선에 깔리는 띠로, 춤의 무대처럼 조각(타일)을 이어 그린다. 물결이 느리게 움직인다(여러 장 스트립).
- 연못 범위: 낚시하는 사람의 몸에서 바라보는 쪽으로 찌 위치 ± 여백. 낚시하는 사람들의 x 를 춤의 `crowds` 와 같은 120pt 기준으로 묶고, 한 무리의 연못은 양 끝 찌를 모두 덮는 하나로 그린다. 혼자여도 연못은 생긴다(춤의 무대는 2명 이상이지만 연못은 1명부터).
- 입질: 찌가 가라앉고 캐릭터와 낚싯대가 좌우로 잘게 흔들린다.
- 잡으면 물고기를 머리 위로 들어 올려 2초 보여 준 뒤 다시 낚시를 이어 간다(접히지 않는다). 드는 동안은 챔질·입질이 없다.
- 헛챔질: 챔질처럼 낚싯대를 휙 올렸다 내리고 빈 찌가 물 밖으로 튀었다 떨어지며 "까비…" 말풍선을 띄운다. 대기 시간은 처음부터 다시 잰다. 헛챔질 횟수를 PosMsg `v` 로 보내 동료 화면에도 보인다.
- 입질 시간 안에 챔질하지 않으면 "놓쳤다…" 말풍선을 띄운다. 낚싯대를 접어 끝난 입질은 알리지 않는다.

## 타이밍 (빌더가 조정 가능)

- 펴고 나서 입질까지 15~40초 무작위.
- 입질은 1초 이어진다. 놓치면 찌가 다시 떠서 처음부터 기다린다.
- 들어 올려 보여 주는 시간 2초.

## 물고기

- 미리 그린 에셋 여러 종. 번호로 전송하므로 뒤에 추가만 한다.
- 목록(17종): 붕어, 잉어, 금붕어, 복어, 가오리, 문어, 게, 장화(꽝), 고등어, 연어, 흰동가리, 메기, 오징어, 새우, 불가사리, 상어, 깡통(꽝).
- 생물은 바늘에 걸린 자리로 매달린다. 물고기는 입, 문어·오징어는 다리로 줄을 감싸고, 게는 집게. 장화·깡통·불가사리는 그대로 걸린다.
- 확률: 흔한 것(붕어·잉어·금붕어)이 대부분, 복어·가오리·문어·게는 드물게, 장화는 가끔. 구체 가중치는 빌더가 정한다.
- 잡는 사람이 뽑아 번호를 보내고, 모든 화면이 같은 물고기를 든다.

## 동료 화면과 호환

- `PosMsg` 에 옵셔널 필드를 더한다(이름은 빌더가 정한다): 낚시 중 여부, 입질 중 여부, 들고 있는 물고기 번호. 옛 버전은 모르는 키를 무시하고 서 있는 캐릭터로 본다.
- `protocolVersion` 은 바꾸지 않는다.
- 동료 화면에서도 낚싯대·찌·연못·입질 흔들림·들어 올린 물고기가 똑같이 보인다. 입질 판정과 챔질 판정은 낚시하는 사람만 한다.
- 내 띠 밖에 선 동료는 연못 무리에 세지 않는다(춤과 같다).

## 에셋

- 낚싯대(드는 자세 포함 여부는 빌더가 정한다. 캐릭터 시트는 바꾸지 않고 무기처럼 별도 노드로 겹친다), 찌 한 장(물에 잠긴 부분은 연못이 가리고, 옅은 사본이 비쳐 보이게 한다), 연못 타일 스트립(물결 4장), 나무 발판, 물고기 17종.
- 기존 규칙대로 Python(Pillow) 스크립트로 그린다(`scripts/make_saber.py`·`make_slime.py` 참고). 움직이는 것은 프레임마다 통째로 그린 스트립으로 만든다. 1px 선은 피한다.
- 연못 타일의 폭·높이는 무대 타일(`dancefloor`)과 같은 방식으로 2배 확대해 띄운다.

## 함께 고칠 곳

- `Control.swift` 의 `HintView` 안내 줄에 `f 낚시` 를 더하고, 낚시 중에는 `x` 가 챔질임을 표시한다.
- README 의 기능 표에 **낚시** 행을 더한다.
- `offikyApp.swift` 의 DEBUG `Bot` 에 낚시 펴기·챔질 동작을 더한다.
- 테스트: `CharacterNode` 단위로 펴기/접기 조건, 입질 뒤 챔질 성공, 헛챔질, 움직이면 접힘을 검증한다. 연못 무리 묶기는 `World.crowds` 와 같은 순수 함수로 두고 1명부터 묶이는 것을 검증한다.

## 하지 않는 것

- 어종·크기 기록, 채팅 알림, 도감, 점수.
- 물고기를 던지거나 동료에게 주는 상호작용.
- 연못 위치를 고정하거나 지형을 두는 것.

## 빌더에게 맡기는 것

- 필드 이름, 가중치, 흔들림 폭, 낚싯대 길이와 찌 위치, 에셋 세부 모양, 타이밍 상수.
